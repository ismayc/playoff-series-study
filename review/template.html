Playoff series review

Every NBA and WNBA playoff series of two or more games, game by game: how both teams shot from three in Game 1 against the rest of the series, each franchise's Game 1s over time, and how the box score moves from Game 1 to the last game. Data: NBA.com.

Blue is the team at home in Game 1 (the higher seed); orange is its opponent. Gap is Game 1 three-point percentage minus Games 2 on, both teams together. Blank before 1984-85 in the NBA, when three-point attempts are missing from most box scores.

Each point is the mean, over every game with that number, of both teams' deviation from their own average for that series, so team strength cancels. The band is a 95% interval. Full-length keeps only series that went the distance, so every game number holds the same series. Exploratory: many rates on one dataset, so read the bands as estimates, not tests.

Data: NBA.com (stats.nba.com box scores), private, non-commercial use. Built by python/07_review.py in the playoff-series-study repo.
